02 · How an idea becomes a working thing

From a rough idea to something real.

    Read the drawings, the datasheets and the way people actually work, before designing anything.

  2. 02

    Find the slow step or the confusing part, and draw the simplest thing that fixes it.

  3. 03

    Write the code myself, model it in 3D where it helps, and check that the engineering is right.
